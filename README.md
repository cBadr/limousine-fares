# قائمة أسعار الليموزين

تطبيق ويب لعرض أسعار تشغيل الليموزين وإدارتها.

- **الواجهة العامة** (`/`): عرض الأسعار، البحث الذكي بالعربية، التصفية حسب المنطقة وفئة السيارة، نسخ السعر لإرساله في رسالة، الطباعة، والتصدير إلى Excel وCSV وPDF.
- **لوحة التحكم** (`/admin`): للأدمن فقط. فيها تعديل الأسعار مباشرة، وإدارة المناطق وفئات السيارات والشروط والإعدادات، والزيادة الجماعية بنسبة أو مبلغ، والمراجعة قبل النشر، وسجل نسخ قابل للاستعادة.

لا يحتاج التطبيق أي مكتبات خارجية، ويكفي Node.js 18 أو أحدث. الخطوط ومكتبة Excel مضمّنة في المشروع، فيعمل بدون إنترنت.

## التشغيل

```bash
npm start
```

بعدها افتح `http://localhost:3000`.

عند أول تشغيل يُنشأ حساب أدمن باسم `admin` بكلمة مرور عشوائية، وتُحفظ في الملف `data/INITIAL_ADMIN.txt`. سجّل الدخول بها، ثم غيّرها من **لوحة التحكم ← الحساب**، واحذف الملف بعد ذلك.

لتحديد بيانات الأدمن بنفسك عند أول تشغيل:

```bash
ADMIN_USER=owner ADMIN_PASSWORD="كلمة-مرور-قوية" npm start
```

## النشر على Vercel

المشروع جاهز للنشر على Vercel: الملفات الثابتة في `public/`، والـ API عبارة عن دالة واحدة في `api/index.js`.
ولأن Vercel لا يحتفظ بالملفات بين الطلبات، تُحفظ البيانات هناك في **Upstash Redis**.

1. اربط قاعدة **Upstash Redis** بالمشروع من لوحة Vercel (قسم Storage). ستُضاف المتغيرات `KV_REST_API_URL` و`KV_REST_API_TOKEN` تلقائياً.
2. أضف هذه المتغيرات من (Settings ← Environment Variables):
   - `SESSION_SECRET`: نص عشوائي طويل (32 حرفاً أو أكثر)، يُستخدم لتوقيع جلسات الدخول.
   - `ADMIN_USER` و`ADMIN_PASSWORD`: بيانات أول حساب أدمن، وتُقرأ عند أول تشغيل فقط. بعد الدخول غيّر كلمة المرور من لوحة التحكم.
3. عند أول طلب تُنشأ قاعدة البيانات من `data/seed.json` تلقائياً.

## متغيرات التشغيل

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `3000` | منفذ الخادم |
| `HOST` | `0.0.0.0` | عنوان الاستماع |
| `SECURE_COOKIE` | — | اضبطه على `1` عند التشغيل خلف HTTPS |
| `DATA_DIR` | `./data` | مكان ملفات البيانات (في حالة التخزين المحلي) |
| `KV_REST_API_URL` / `KV_REST_API_TOKEN` | — | عند ضبطهما تُحفظ البيانات في Redis بدل الملفات |
| `SESSION_SECRET` | يُولَّد محلياً | مفتاح توقيع الجلسات، ومطلوب على Vercel |
| `ADMIN_USER` / `ADMIN_PASSWORD` | `admin` / عشوائية | بيانات أول حساب أدمن |

## البيانات

| الملف | المحتوى |
|---|---|
| `data/seed.json` | الأسعار الأصلية المستوردة من ملف الإكسل، وتُستخدم عند أول تشغيل فقط |
| `data/db.json` | القائمة المنشورة حالياً |
| `data/history/` | نسخة كاملة عند كل نشر (آخر 60 نسخة) |
| `data/users.json` | حسابات الأدمن، وكلمات المرور فيه مشفّرة بـ scrypt |

لإعادة توليد `seed.json` من ملف إكسل بنفس التنسيق:

```bash
python -I scripts/import_xlsx.py "قائمة الأسعار.xlsx" data/seed.json
```

بعدها احذف `data/db.json` ليُعاد إنشاؤه من الملف الجديد.

## طريقة العمل في لوحة التحكم

1. كل تعديل يُحفظ أولاً **كمسودة**، ولا يراه المستخدمون. الخلايا التي تغيّرت تظهر مميّزة، وعند المرور عليها يظهر السعر القديم.
2. زر **مراجعة ونشر** يعرض قائمة بكل التغييرات (القيمة القديمة ← الجديدة) قبل النشر. الاختصار: `Ctrl+S`.
3. قبل النشر تُحفظ نسخة تلقائياً، ويمكن استعادة أي نسخة سابقة من **سجل النسخ**.
4. المسودة محفوظة على جهازك، فلا تضيع إذا أغلقت الصفحة أو انتهت الجلسة.

## الأمان

- كل مسارات التعديل تشترط جلسة أدمن موقّعة بـ HMAC. الكوكي من نوع `HttpOnly` و`SameSite=Strict`، وتنتهي بعد 8 ساعات من عدم النشاط. تغيير كلمة المرور يُلغي كل الجلسات الأخرى.
- بعد 5 محاولات دخول فاشلة يُوقف الدخول من نفس العنوان لمدة 15 دقيقة.
- طلبات التعديل يجب أن تأتي من نفس الموقع وبصيغة JSON. وسياسة CSP صارمة تمنع أي سكربت خارجي.
- الخادم يتحقق من كل البيانات المرسلة قبل حفظها.
- عند النشر على الإنترنت شغّل التطبيق خلف HTTPS واضبط `SECURE_COOKIE=1`.
